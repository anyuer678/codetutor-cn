# CodeTutor CN —— 中文代码教学器

> 贴一段代码进去，它像老师一样逐步讲「这段代码在干什么、每个部分为什么这么写」，还能出练习题验你会没会。

纯静态单页工具：本地双击即用，零框架、零第三方依赖。面向「小学生也能看懂」的中文教学，支持 幼儿园 / 小学生 / 初中生 / 成人 四个年龄段的词汇分级。

## 功能特性

| 能力 | 说明 |
|---|---|
| 五步教学流程 | 概述 → 分块讲解 → 词汇表 → 提问测试 → 改写挑战 |
| 年龄分级 | 四个年龄段词表自动切换（如幼儿园讲 `for` 循环用「三个人排队」） |
| 逐块重讲 | 任何一块没听懂，点「重新讲得更简单」自动降龄重讲 |
| 练习闭环 | 3 道选择题（答案先隐藏，作答后显示解析）+ 改写挑战参考思路 |
| 零依赖 | 纯标准库 Python 代理 + 原生 JS，`file://` 直接可用 |
| 隐私保护 | 粘贴的代码只在本机浏览器内存处理，localStorage 不存代码 |

## 快速开始

### 方式一：本地直接打开（最简单）

1. 用浏览器打开 `index.html`（双击即可，无需服务器）。
2. 右上角「接口设置」填入 OpenAI 兼容 API 的地址、模型与 Key（字节/DeepSeek/通义均可）。
3. 点「填入示例」快速体验，或粘贴代码，点「开始讲解」（快捷键 Ctrl+Enter）。

### 方式二：本地代理（推荐，解决 CORS 并保护 key）

```bash
$env:LLM_API_KEY = "sk-你的key"     # 可选：LLM_API_BASE / LLM_MODEL / PORT
python server.py
```

浏览器打开 `http://127.0.0.1:8000`，接口设置里 **API Key 留空**（代理从环境变量取 key，key 不出现在前端、不落盘）。

## 五步教学流程

1. **这段代码在做什么** —— 一句话概述（当前年龄段词汇）
2. **分块讲解** —— 按语义块（非按行）3-8 块，每块「在做什么 + 为什么这么写」，可逐块重讲
3. **关键词汇表** —— 术语 / 含义 / 生活类比
4. **提问测试** —— 3 道选择题，答案先隐藏，作答后显示正确项与解析
5. **改写挑战** —— 改一个数字/条件看会发生什么，附参考思路

## 项目结构

```
index.html      单页骨架 + 样式（普通 script 顺序加载，file:// 可用）
prompts.js      年龄分级词表 + 角色卡 + JSON 契约（纯文本，无网络）
storage.js      localStorage（只存年龄偏好/配置/学习标签，不存代码）
llm.js          网络唯一出口：请求/超时/契约校验/容错重试
state.js        教学会话状态机（五步推进、重讲、练答判定）
ui.js           DOM 渲染与交互（renderStep 纯函数返回 HTML）
server.py       可选本地代理：CORS 转发 + key 保护
examples/       3 组演示用例（5 行 / 20 行 / 50 行含报错）
tests/          pytest（词表契约）+ node --test（JS 逻辑）测试
```

## 测试

```bash
# Python 契约测试（词表映射、禁用词断言、JSON 契约）
python -m pytest tests/test_prompt.py -q

# JS 逻辑测试（契约校验容错、渲染五步、答案隐藏、状态机、浏览器全流程集成）
node --test tests/
```
