# 中文代码教学器（CodeTutor CN）

> 贴一段代码进去，它像老师一样逐步讲"这段代码在干什么、每个部分为什么这么写"，还能出练习题验你会没会。

纯静态单页工具：本地双击即用，零框架、零第三方依赖。面向"小学生也能看懂"的中文教学，支持 幼儿园 / 小学生 / 初中生 / 成人 四个年龄段的词汇分级。

## 快速开始

### 方式一：本地直接打开（最简单）
1. 用浏览器打开本目录的 `index.html`（双击即可，无需服务器）。
2. 右上角 ⚙ 接口设置：填入 OpenAI 兼容 API 的地址、模型与 Key（字节/DeepSeek/通义均可）。
3. 点"✨ 填入示例"快速体验，或粘贴一段代码，点"开始讲解"（快捷键 Ctrl+Enter）。

### 方式二：本地代理（推荐，解决 CORS 并保护 key）
```bash
# Windows PowerShell
$env:LLM_API_KEY = "sk-你的key"     # 可选：LLM_API_BASE / LLM_MODEL / PORT
python server.py
```
然后浏览器打开 `http://127.0.0.1:8000`，接口设置里 **API Key 留空**（代理从环境变量取 key，key 不出现在前端、不落盘）。

## 使用示例

0. 点"✨ 填入示例"体验内置示例代码（幼儿园档讲 for 循环）；页面顶部有五步进度指示器，讲解时显示骨架屏，完成出现"⑤ 完成"卡片。
1. 打开页面 → 年龄段选"幼儿园" → 粘贴 `examples/demo_5_lines.py` → 开始讲解（`for i in range(3)` 会用"三个人排队"来讲）。
2. 任何一块没听懂 → 点该块下"重新讲得更简单"（自动切换 6 岁词汇重讲这一块）。
3. 做 3 道选择题：先想后答，答完才显示正确答案（绿）与你的选择（错即红）与解析。
4. 完成"改写挑战"→ 看参考思路 → 课程标签记入本机学习历史（不存代码）。
5. 中途切换年龄段（如 幼儿园→成人），讲解会用新词表重新生成（旧卡片自动清空）。

## 目录结构

```
index.html      单页骨架 + 样式（普通 script 顺序加载，file:// 可用）
prompts.js      年龄分级词表 + 角色卡 + JSON 契约（纯文本，无网络）
storage.js      localStorage（只存年龄偏好/配置/学习标签，不存代码）
llm.js          网络唯一出口：请求/超时/契约校验/容错重试
state.js        教学会话状态机（五步推进、重讲、练答判定）
ui.js           DOM 渲染与交互（renderStep 纯函数返回 HTML）
server.py       可选本地代理：CORS 转发 + key 保护
examples/       3 组演示用例（5 行 / 20 行 / 50 行含报错）
tests/          pytest（词表契约）+ node --test（JS 逻辑）测试
```

## 五步教学流程

1. **① 这段代码在做什么** —— 一句话概述（当前年龄段词汇）
2. **② 分块讲解** —— 按语义块（非按行）3-8 块，每块"在做什么 + 为什么这么写"；每块可"重新讲得更简单"
3. **③ 关键词汇表** —— 术语 / 含义 / 生活类比
4. **④ 提问测试** —— 3 道选择题，**答案先隐藏，作答后才显示**正确项与解析
5. **⑤ 改写挑战** —— 改一个数字/条件看会发生什么，附参考思路

## 隐私与免责

- 你粘贴的代码**只在本机浏览器内存**中处理；不上传除你配置的 API 端点以外的任何地方。
- localStorage 只存年龄偏好、接口配置与课程标签，**不存代码本身**。
- 本地代理 `server.py` 不落盘、不记录请求内容；key 仅从环境变量读取。
- 讲解由 AI 生成，**如有疑义请向真人老师确认**；每个类比仅供参考。

## 已知限制

- 浏览器直调部分 API 会因 CORS 失败 → 请使用 `server.py` 代理或支持 CORS 的网关。
- LLM 响应超过 30 秒会提示"再试一次"（可缩小代码篇幅）。
- 纯自学习工具，非认证课程，无账号体系。
